### 01. 🚀 [Smart-Drive](https://github.com/PARTHPIPALIYA1101/Smart-Drive)
> **Unified Cloud Virtual Filesystem & Multi-Account Drive Pooling Engine**

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                 Client Application / Web Portal / Upload Queue              │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ (Chunked Streams / SSE Progress Events)
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                 Fastify REST API & Domain VFS Engine                        │
│   ├── Unified Virtual Filesystem (VFS) Tree & Folder Hierarchy             │
│   ├── Smart Placement Engine (Space-Optimized Target Drive Allocation)      │
│   ├── Concurrent Space Reservation Manager & Crash Recovery Engine         │
│   └── AES-256 Cryptographic OAuth Token Security Layer                     │
└───────────────────┬──────────────────┬──────────────────┬───────────────────┘
                    │                  │                  │
                    ▼                  ▼                  ▼
             ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
             │ Drive Acct  │    │ Drive Acct  │    │ Drive Acct  │
             │   Alpha     │    │    Beta     │    │    Gamma    │
             │   [15 GB]   │    │   [15 GB]   │    │   [15 GB]   │
             └─────────────┘    └─────────────┘    └─────────────┘
                    ▲                  ▲                  ▲
                    └──────────────────┴──────────────────┘
                 Aggregated Unified Storage Pool (45 GB+ Dynamic)
```

- **Architecture**: Domain-Driven Design (DDD) Virtual Filesystem with space reservation, crash recovery, and zero-downtime drive retirement migration planner.
- **Tech Stack**: `TypeScript` | `Fastify` | `Drizzle ORM` | `Google Drive API` | `AES-256 Crypto` | `Server-Sent Events (SSE)` | `Vitest`
- **Core Features**:
  - **Multi-Account Storage Pooling**: Connect unlimited Google Drive accounts to seamlessly fuse their capacities into one giant virtual drive.
  - **Smart Space Placement**: Uploads automatically route to the account with the highest free space with reservation locks to prevent race-condition over-allocation.
  - **Safe Drive Retirement & Migration Planner**: One-click retirement safely evacuates and migrates all files across sibling connected drives before disconnecting an account.
  - **Enterprise Security & Real-Time Sync**: AES-256 encryption at rest for OAuth tokens; SSE live stream updates for chunk uploads, batch folder trees, and live capacity analytics.
- **Complexity**: `★★★★★ [ENTERPRISE VFS]`

- **Core Features**:

  - **YOLOv11 + ByteTrack + ANPR Pipeline**: Automatic vehicle identification, plate localization (`license-plate-finetune-v1n.pt`), and optical character recognition synced into PostGIS spatial coordinates.
  - **Dual-Stream Control Room Matrix**: Instant toggle between raw RTSP feed and AI annotated bounding box telemetry with multi-grid layouts (1x1, 2x2, 3x3, 4x4).
  - **Multi-Role RBAC & Audit Trail**: 5-tier role hierarchy (`STATE_ADMIN` to `OPERATOR`) with departmental isolation and append-only tamper-proof audit logging.
